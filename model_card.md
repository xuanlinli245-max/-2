# Model Card: Модель прогнозирования улучшения физической подготовки

## 1. Детали модели (Model Details)
*   **Название модели**: Модель прогнозирования улучшения физической подготовки (Physical Fitness Improvement Prediction Model)
*   **Версия**: v1.0
*   **Тип модели**: Обучение с учителем / Множественная линейная регрессия (Multiple Linear Regression)
*   **Разработчик**: [你的名字 / Ваше имя]
*   **Область применения**: Спортивная наука / Умные фитнес-ассистенты

## 2. Предполагаемое использование (Intended Use)
*   **Основная цель**: На основе базовых физических данных пользователя, состава тела, базовых кардиопоказателей и ежедневной тренировочной нагрузки **прогнозировать взвешенный балл физической подготовки** пользователя на следующем этапе (и, следовательно, оценивать коэффициент улучшения физической формы).
*   **Основные пользователи**: Фитнес-тренеры, пользователи приложений для физической подготовки.
*   **Сценарии применения**: Используется для динамической корректировки планов тренировок. Например, если модель предсказывает очень незначительный прирост баллов в следующем месяце (низкий коэффициент улучшения), тренер может заранее увеличить объем тренировок или скорректировать план отдыха. Если прогнозируется аномальное снижение баллов, система предупреждает о риске перетренированности.
*   **Неприменимые сценарии**: Не подходит для прогнозирования сроков восстановления после травм; не применимо к новым пользователям без исторических данных ("холодный старт").

## 3. Входные и выходные данные (Inputs & Outputs)
*   **Входные данные (Features / Признаки)**:
    1. `height` (Рост, см) - непрерывное числовое значение
    2. `weight` (Вес, кг) - непрерывное числовое значение
    3. `body_composition` (Основной состав тела, например, процент жира или мышечная масса) - непрерывное числовое значение
    4. `training_volume` (Объем тренировок с собственным весом / тренировочная нагрузка) - непрерывное числовое значение
    5. `rest_quality` (Качество восстановления / продолжительность сна) - непрерывное числовое значение
    6. `cardio_index` (Базовые кардиопоказатели, например, ЧСС в покое) - непрерывное числовое значение
*   **Выходные данные (Target Variable / Целевая переменная)**:
    *   Прогнозируемый **`weighted_fitness_score` (Взвешенный балл физической подготовки)**. Это непрерывное число с плавающей запятой.
    *   *Бизнес-производная*: Сравнивая прогнозируемый балл с текущим баллом, можно рассчитать ожидаемый "коэффициент улучшения физической подготовки".

## 4. Метрики качества (Metrics)
Для оценки эффективности модели на исторических данных пользователей используются:
*   **MAE (Средняя абсолютная ошибка)**: Измеряет среднее отклонение между прогнозируемым и фактическим баллом.
*   **RMSE (Среднеквадратичная ошибка)**: Оценивает стабильность прогнозов модели в экстремальных условиях.
*   **R-squared (\(R^2\))**: Оценивает, в какой степени такие признаки, как рост и объем тренировок, объясняют дисперсию баллов физической подготовки.

## 5. Ограничения (Limitations)
*   **Нелинейные ограничения**: Линейная регрессия предполагает линейный рост физической формы с увеличением объема тренировок. Однако в реальности у человека существуют "плато" (застои) и негативный рост из-за перетренированности, которые данная модель не может идеально уловить.
*   **Зависимость от данных**: Точность прогноза сильно зависит от достоверности вводимых пользователем данных (например, завышение объема тренировок или продолжительности сна).
*   **Упущенные признаки**: В модель не включены трудно поддающиеся количественной оценке факторы, такие как структура питания и психологический стресс, что может привести к ошибкам прогнозирования.
